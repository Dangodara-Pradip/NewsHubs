# 📖 Overview

GNews App is a modern web application developed using **React.js** that allows users to stay updated with the latest news from multiple categories including Business, Technology, Sports, Entertainment, Health, Science, and General News. It integrates the GNews REST API to fetch real-time news articles and presents them through a responsive and user-friendly interface.
